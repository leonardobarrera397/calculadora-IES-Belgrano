# 🧮 Calculadora Windows XP

Este proyecto es un **Trabajo Práctico** desarrollado para la materia **Prácticas Profesionalizantes** de la carrera de **Desarrollo de Software** (o afín) en el **IES Manuel Belgrano**.

Consiste en una calculadora web interactiva construida con tecnologías estándar del desarrollo web frontend (**HTML5, CSS3 y JavaScript Vanilla**), adaptada visualmente con una interfaz retro que emula el icónico estilo visual **Luna (Azul)** de **Windows XP**.

---

## 📸 Vista Previa

> *Una calculadora con el diseño nostálgico del clásico sistema operativo Windows XP, que incluye ventanas retro, botones en 3D con degradados, biseles hundidos (*inset*) para el display y el fondo clásico "Bliss".*

---

## 🚀 Características

- **Lógica Matemática:**
  - Operaciones básicas: Suma (`+`), Resta (`-`), Multiplicación (`*`) y División (`/`).
  - Soporte para números decimales.
  - Función de limpieza total (`C`).
  - Control de errores, como el manejo de divisiones por cero con alertas integradas.
- **Diseño Estilizado:**
  - Interfaz gráfica basada en el estilo clásico **Windows XP Luna**.
  - Visualización dual de entradas (campo de operación auxiliar y pantalla principal de resultado).
  - Efectos visuales interactivos al pasar el ratón (*hover*) y al hacer clic (*active*).
  - Totalmente adaptativo y accesible.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica para los botones, campos de entrada y contenedores de la aplicación.
- **CSS3:** Estilizado avanzado con degradados lineales, bordes retro, sombras internas (*box-shadows*) y tipografía personalizada para simular la interfaz de usuario de Windows XP.
- **JavaScript (Vanilla):** Lógica funcional para capturar eventos del DOM, procesar operaciones matemáticas y gestionar el flujo de datos sin dependencias externas.
